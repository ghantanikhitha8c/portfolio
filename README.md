# Nikhitha Priya — Student Portfolio

A responsive, dark-themed personal portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run the website

1. Open this project folder in VS Code.
2. Open `index.html` in a browser. You can double-click it in File Explorer, or use VS Code's **Open with Live Server** command if you have the Live Server extension installed.
3. If using Live Server, right-click `index.html` and choose **Open with Live Server**. The browser will open the local site.

## Personalize the portfolio

- Update the college academic year in the Education section in `index.html`.
- Replace the example email, GitHub, and LinkedIn links in `index.html` with your own before publishing.
- Add projects to the `projects` array in `script.js`. Each entry includes a name, description, technologies, GitHub repository, live demo, category, and preview style. The section currently shows an honest empty state.
- Add verified credentials to the `certifications` array in `script.js` using `name`, `issuer`, and optional `date` and `url` properties. The page does not claim certifications that have not been provided.
- Add any other skills you know to the `skillGroups` array in `script.js`.
- The hero portrait uses `profile-photo.png`. Replace that file to update the photo; its crop and framing are styled in `styles.css`.
- Update `resume-template.txt` with your own contact details and any additional verified experience before downloading or sharing it.

The design respects the system's reduced-motion preference. The web font is loaded from Google Fonts; system font fallbacks are included in `styles.css`.
